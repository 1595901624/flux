## Экран сурәтләре

### Баш бит

Система проксиен һәм маршрутлаштыру режимын идарә итегез; актив профильне, сайланган төенне, агымдагы трафикны һәм үзәкнең торышын карагыз.

![Flux баш бите: прокси көйләүләре, профиль, трафик һәм үзәк турында мәгълүмат](screenshots/home.png)

### Проксилар

Прокси төркемнәрен карагыз, төеннәрне исем яки төр буенча сөзегез, төенне алыштырыгыз һәм тоткарлыкны тикшерегез.

![Flux прокси идарәсе: режимнар, төркемнәр, төен сайлау һәм тоткарлык сынавы](screenshots/proxies.png)

Сурәтләрдә [`sample-profile.yaml`](sample-profile.yaml) күрсәтмә профиле кулланыла. Сервер адреслары үрнәк өчен генә бирелгән һәм чын прокси буларак эшләми.

## Мөмкинлекләр

- **Windows өчен табигый интерфейс** — WinUI 3, Mica фоны, Fluent Design һәм күп телле интерфейс.
- **Сыгылмалы маршрутлаштыру** — Rule, Global һәм Direct режимнары, система проксие һәм TUN белән идарә итү.
- **Профильләр белән идарә итү** — Clash белән ярашлы YAML файлларын яки язылу сылтамаларын кертү, профильне алыштыру һәм язылуларны яңарту.
- **Төеннәр белән идарә итү** — Төен сайлау, исем яки төр буенча сөзү, прокси тәэмин итүчеләрен карау һәм тоткарлыкны тикшерү.
- **Трафик һәм диагностика** — Җибәрү һәм кабул итү тизлеге графиклары, актив тоташулар, кагыйдәләр, үзәк журналлары һәм хезмәтләргә керүне тикшерү.
- **Система трее** — Тәрәзәне япкач, Flux трейга яшерелә. Чыгу өчен трей менюсын кулланыгыз.
- **Башкару мохите кертелгән** — Тарату җыелмаларына mihomo, .NET һәм Windows App SDK компонентлары керә.

## Эшне башлау

**Windows 10 2004 версиясе (19041 җыелмасы) һәм яңарак версияләр**, x86, x64 һәм ARM64 архитектуралары хуплана.

1. [Чыгарылышлар битендә](https://github.com/1595901624/flux/releases) Windows архитектурасына туры килгән пакетны сайлагыз һәм шул чыгарылышның урнаштыру күрсәтмәләрен үтәгез. Кибеттән тыш урнаштыру ZIP-ын ачып, эчендәге `Install-FluxSideload.ps1` файлын администратор исеменнән эшләтегез.
2. Flux-ны эшләтеп, **Profiles** бүлегендә язылу сылтамасын яки җирле YAML файлын кертегез. Активлаштыру өчен профильне сайлагыз.
3. **Proxies** бүлегендә төен яки төркем сайлагыз. **Rule** режимы трафикны профиль кагыйдәләре буенча юнәлтә.
4. Windows прокси көйләүләрен үтәүче кушымталар Flux-ны куллансын өчен, **Home** битендә **System proxy** күчергечен кабызыгыз.

TUN режимына администратор хокуклары яки эшли торган Flux өстенлекле хезмәте кирәк. Тәрәзәне япкач та, Flux трейда эшләвен дәвам итә.

CI ясаган имзасыз MSIX файллары эшләү барышындагы сынаулар өчен генә. Күчерелмә ZIP бирелсә, аны ачып `Flux.exe` файлын эшләтегез.

## Көйләүләр һәм мәгълүмат

Flux `proxies`, `proxy-groups` һәм `rules` бүлекләре булган, Clash белән ярашлы YAML профильләрен куллана. Үрнәк: [`sample-profile.yaml`](sample-profile.yaml). Үзегезнең гамәлдәге сервер мәгълүматын яки язылу сылтамасын кулланыгыз; Flux прокси язылуы бирми.

Көйләүләр, профильләр һәм журналлар гадәттә `%APPDATA%\flux` эчендә саклана. Язу мөмкинлеге булган каталогтагы күчерелмә версия өчен, эшләтер алдыннан `Flux.exe` янында буш `.config\PORTABLE` файлын ясагыз: мәгълүмат `.config\flux` эчендә сакланачак.

## Чыганак кодтан җыю

Windows системасында [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) урнаштырыгыз. Проект WinUI 3 куллана һәм Windows SDK `10.0.22621.0` версиясенә юнәлтелгән. IDE өчен .NET 10 һәм WinUI 3 белән эшли алган Visual Studio версиясен сайлагыз.

```powershell
git clone https://github.com/1595901624/flux.git
cd flux
dotnet restore Flux.slnx
dotnet build Flux.csproj -c Release
dotnet run --project Flux.csproj -c Release --no-build
```

Килешү буенча максат — `win-x64`. Башка архитектура өчен `-r win-x86` яки `-r win-arm64` күрсәтегез. Репозиторийда һәр максатка туры килгән mihomo үзәге бар.

Сынауларны эшләтү:

```powershell
dotnet test tests/Flux.Tests/Flux.Tests.csproj -c Release
```

Өстенлекле хезмәтне дә кертеп тарату пакетларын әзерләү өчен [җыю эш агымын](.github/workflows/build-msix.yml) карагыз.
